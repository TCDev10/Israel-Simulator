# Welcome to the Israel-Simulator Wiki

Welcome to the official documentation and comprehensive guide for **Israel-Simulator**, an immersive Minecraft Java Edition mod built on **NeoForge 26.2** (Minecraft 26.2).

Israel-Simulator brings the rich landscapes, historic landmarks, culture, gastronomy, economy, and dynamic life of Israel into Minecraft sandbox gameplay.

## ⚡ Installation & Getting Started

1. **Requirements:**
   * Minecraft Java Edition **26.2**
   * **NeoForge 26.2.0.88** or newer
   * Java **25** runtime
2. **Download:**
   * Grab the latest release `.jar` from GitHub Releases, CurseForge, or Modrinth.
   * Place the jar into your `.minecraft/mods` folder.
3. **World Creation:**
   * Create a standard Overworld — Israel-Simulator biomes and structures naturally generate within the multi-noise climate pipeline.

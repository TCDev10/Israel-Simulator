## Locating Structures

Admins and beta testers can locate any structure using the standard Minecraft command:

```text
/locate structure israel_simulator:<structure_id>
```

Example:
```text
/locate structure israel_simulator:western_wall
/locate structure israel_simulator:tel_aviv_city
/locate structure israel_simulator:great_synagogue
```
